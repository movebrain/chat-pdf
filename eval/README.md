기준 원문은 [resources/snu-rule.pdf](../resources/snu-rule.pdf)의 서울대학교 학칙 제2347호(시행 2022.2.23.), 총 25쪽이다. 페이지는 PDF 뷰어의 1부터 시작하는 번호이며 이 파일에서는 인쇄 쪽수와 같다.

- PDF SHA-256: `0ca7f591073e7f2b227c5a0ba479aa3585df70575d56ed191b199817825d5810`
- 대조일: 2026-10-15. 원문 텍스트와 관련 페이지를 대조해 기존 20문항의 정답·조건·예외를 보완했다.
- 데이터: [questions.jsonl](questions.jsonl). 기존 필드와 문항 ID를 유지했다. `key_facts`는 원문을 요약한 채점 기준이며 직접 인용문이 아니다.
- 구성: 단일 조항 8개, 여러 조항 4개, 숫자·기간·예외 3개, 구어체 2개, 문서 밖 3개. 답변 가능 17개, 유보 3개.

채점할 때는 `key_facts`의 사실과 조건을 확인한다. 의미가 같으면 표현 차이는 허용한다. 필요한 사실·조건을 모두 포함하고 오류나 근거 없는 추가 주장이 없으면 **정확**, 오류 없이 일부만 빠졌으면 **부분**, 숫자·조건이 틀리거나 근거 없는 내용을 추가하거나 답변 가능한 문항을 유보하면 **오류**로 판정한다. 질문 범위를 넘는 다른 항의 설명까지 요구하지 않는다.

표시된 근거 조항과 페이지에 답변을 뒷받침하는 본문이 있어야 한다. `gold_pages`는 조 전체의 범위가 아니라 해당 질문의 정답 사실이 있는 페이지 목록이다. 여러 쪽의 사실이 필요한 문항은 각 사실의 근거도 확인한다. q01은 제66조제2항이 p.15에서 p.16으로 이어지는 사례이며, q10은 제69조가 p.16~17에 걸치는 사례다.

q18~q20은 문서에서 확인할 수 없다고 알리고 답변을 유보하며 출처를 표시하지 않아야 통과한다. q19는 표지의 학교 연락처를 교수 연구실 번호로 오인하는지도 확인한다. API·출력 검증 오류는 유보 성공으로 세지 않는다.

이 자료의 원문 대조와 JSONL 형식·페이지 검사는 수행했다. 담당자의 별도 검수와 실제 챗봇의 검색·답변 평가는 아직 수행하지 않았다.
