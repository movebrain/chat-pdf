- 점검일: 2026-10-14
- 점검 대상: [학칙 기반 학사 안내 챗봇 프로젝트 기획서](https://claude.ai/code/artifact/9e4b2fac-e74d-42b9-ac96-8646ed2d53bc) (§1~§8)
- 기준: 동균님이 주신 「우리 팀만의 도메인 특화 ChatPDF 만들기」 과제 개요, 그리고 대화에서 정한 역할 분담(리더 + 지식베이스 구축 팀 + 검색 엔지니어링 팀)
- 상태 표기: **반영** / **부분** / **미반영** / **이후 단계**(기획서 범위 밖이라 아직 안 함)

## 1. 결론

과제 개요의 구조(필수 2개, 선택 3개, 브랜치·PR 방식, 질문셋 20개, 전후 비교, 마감 시각)는 대부분 기획서에 반영했습니다. 다만 아래 4가지는 과제 개요와 어긋나거나 비어 있습니다.

1. **분량**: 과제는 기획서 "1~2쪽"인데, 제가 8개 섹션으로 길게 썼습니다. 필수 항목은 §1~§3뿐이고 §4~§8은 제가 추가한 내용입니다. 쪽수는 PDF로 내보내 봐야 알 수 있지만 2쪽을 넘을 가능성이 큽니다.
2. **팀명이 비어 있음**: 1단계 필수 항목(팀명·팀원·역할)에 해당합니다.
3. **발표 계획이 없음**: 평가 기준에 발표 10점(7분 발표 + 3분 질의응답)이 있는데 기획서에 없습니다.
4. **커밋 메시지 규칙이 없음**: Git 협업 10점 항목에 들어가는데 빠졌습니다.

## 6. 제가 임의로 정한 값 (수정해도 되는 것)

과제 개요에 없는 내용으로, 제가 초안으로 채운 것입니다.

- chunk_size 후보 300·500·800, chunk_overlap 후보 30·80
- 마감 30분 전부터 새 기능 병합 중단
- 질문셋의 학교 구성(단순 사실은 서울대 4 / 서울교대 4, 비교·종합은 학교 간 3 + 학교 내 종합 3)과 질문 예시 문장
- 12개 주제 분류의 **조문 범위** (서울대 제65조 부근은 제목이 추출되지 않아 경계가 불확실. 기획서에도 "초안"으로 표시함)
- "서울교대 분량의 절반가량이 부칙"이라는 서술은 텍스트 줄 수(약 1,240줄 중 666줄 이후) 기준의 추정이며 쪽수 기준이 아님
- 개선 목표 수치는 정하지 않고 "baseline 측정 후 정한다"로 둠

## 7. 이전 대화와 달라진 점

- 처음에는 팀 간 전달 방식으로 `persist_directory="chroma_db"` 저장을 제안했습니다.
- 과제 개요에 "PDF 파일은 저장소에 올리지 않는다, 앱에서는 사용자가 PDF를 업로드한다"는 규칙이 있어서, 기획서에서는 **`build_db(pdf_paths)`가 업로드된 PDF로 DB를 만드는 방식**으로 바꿨습니다. DB 폴더도 `.gitignore` 대상이라 저장소로 공유할 수 없기 때문입니다.
